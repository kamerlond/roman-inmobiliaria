# Roman Inmobiliaria

Web inmobiliaria construida con React + Vite + Supabase.

## Arrancar en local

```bash
npm install
npm run dev
```

## Build para producción

```bash
npm run build
```

El directorio `dist/` es directamente deployable en Netlify.

## Acceso al panel admin

Navega a `/#/admin` → Usuario: `admin` · Contraseña: `roman2026`
